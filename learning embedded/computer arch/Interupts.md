an interrupt is a signal that causes the processor to stop its current execution and divert its attention to a high priority task. 
* [[IRQ/IRL]] is a hardware line that is used to create an interrupt
* [[ISR]] is a [[software routine]] that handles the interrupt 

__definitions__
- _interrupt latency_ is the delay between receiving the interrupt and starting the [[ISR]]

## hardware [[cheat sheets/bashShortcuts]]
hardware interrupts are in response to a physical device on the system. a single request line is used for all the devices. To request an interrupt the device closes its associated latch. the interrupt value itself is the OR of these devices

* __maskable__ 
* __spurious__
