#networking 

in a link state routing protocol, every router creates a connectivity map of the network. For each router to have this information about its  neighboring connections this information is advertised. these advertisements are passed along to other routers until all routers in the network develop the same network map. [[routing|routers]] use this map to calculate the best route to each destination. 

- more resource demanding than others 
- fast at reacting to changes in a network
