Wired networks allow devices to transfer data trough fiber and copper cables, [[WiFi]] networks transmit data though the air using microwaves in accordance with the antenna's pattern, and it could reach any other __WiFi__ enabled device in that range. 

# WEP

__Wired Equivalent Privacy__ is a security option that uses the __RC4 cipher algorithm__ to encrpyt every frame so that eavesdroppers can't read the contents. it uses a static key to encrypt data, which is shared between the router and other devices. 

- **Open Authentication –** The wireless client doesn’t provide any credentials and only uses WEP encryption to encrypt data frames.
- **Shared Key Authentication –** WEP key is used for both authentication and encryption.
