__IEEE 802.1Q__ also known as __dot1q__ is the networking standard that supports [[VLAN]] on an __IEEE 802.3__ [[ethernet]] network. 




# TAG

![[Pasted image 20260929143239.png]]

- __TPID__ tag protocol identifier always set to `0x8100` this indicates that the [[frames|frame]] is tagged as a __802.1Q__
- __TCI__ tag control information 
- __PCP__ is used for [[CoS]] 
- __DEI__ is used to indicate frames that can be dropped if the network is congested 
- __VID__ identifies the [[VLAN]] the from belongs to __range__ `1-4094`
	- Normal [[VLAN|VLAN's]] `1-1005`
	- Extended [[VLAN|VLAN's]] `1006-4094`
	- _some older devices do not use extended_
